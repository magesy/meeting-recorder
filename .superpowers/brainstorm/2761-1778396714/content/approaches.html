How should we build the Meeting Recorder?

A

The Lean Hybrid (React Native + Expo)

Speed: Fastest to build and iterate.

Tech: TypeScript, Expo AV for recording, and a simple Node.js or Python backend.

Pros: Easy to add UI features later; runs great on your S24.

B

The Power Native (Kotlin + Jetpack Compose)

Control: Maximum audio quality and reliability.

Tech: Kotlin, Android MediaRecorder, Foregound Services for long meetings.

Pros: Best handling of the S24's mic array and background recording stability.

C

The Web-First (PWA / Next.js)

Access: Zero installation required.

Tech: React/Next.js, Web Audio API.

Pros: Works on any device, but background recording can be restricted by Android battery settings.

Common Core (AI)

  • Transcription: OpenAI Whisper (Industry leader for Thai/English).
  • Summarization: Gemini 1.5 Flash/Pro (Superior Thai context & MoM formatting).

My Recommendation: Option A (Expo). It provides a "native" feel with high reliability for background recording, but we can build it much faster than a pure native app.
