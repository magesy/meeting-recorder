Architecture: System Flow

React Native + Expo App with AI Backend

Data Pipeline
1. Mobile App (Android)

Record audio (AAC/M4A) via Expo AV. Store locally during meeting.

↓
2. Backend Processing

Upload audio to a Python/FastAPI or Node.js backend. Handle large file chunks.

↓
3a. OpenAI Whisper

Thai/English Speech-to-Text conversion.

3b. Google Gemini

Extract Action Items & generate MoM.

↓
4. Final Output

View Transcript & MoM in the app. Export to PDF/Markdown.

Does this data flow make sense? We'll focus on ensuring the app can handle 1-2 hour long recordings without crashing or losing data.
